# T3 本周时间分配页面

`/board` 使用上海时区的本周一和今天调用 `week_allocation`，原样保留 `allocation` 上下文，并为两个层级增加展示用百分比、扇区起点和颜色。历史日报仍使用选中日；新增分配模块固定显示当前周。

本周分析之后新增一级分类 / 二级标签分段按钮。同一位置切换 `hidden`，不发请求；原生按钮支持 Tab、Enter、空格，`aria-pressed` 和 `aria-controls` 标记当前视图。今日与周分配共用 SVG 环形图宏，保留今日原有 Top 5 + 其他、未知时长处理和悬停行为。

直接使用 T2 的分类与标签合并结果，不二次聚合。中心为一位小数总小时；图例为一位小数小时和最大余数法整数百分比（合计 100%）。二级标签附分类小字。六个现有配色加其他 / 未分类中性色；未分类始终单列。总分钟为零不渲染分配 SVG；未知时长附注保留。周分配 AI 解读不在本票生成，缺失时显示「解读未生成」。

390px 环形图与图例堆叠，分段按钮不换行；标题必要时与整个控件分行。无图表依赖。
