# 看板 T5：本周柱状图与今日环形图

用原生 SVG、CSS 和轻量事件监听替换占比条，不新增依赖。数据统计、AI 分析和调度保持原行为；`board.py`、`board_analysis.py` 未修改。`board_page.py` 只新增展示数据整形，查询及写入流程不变。

## 展示规则

- 页面顺序为数字卡、本周图、今日图与原明细、日/周分析、历史；区块间距 32px，移除看板内分隔线。
- 本周补齐周一至周日七个槽位，标题右端按示例显示下周一（区间右开）。统计仍截止选中日，后续日期不冒充零会议。今天同时使用 accent 和「今天」文字标记。
- 条宽除以可见日期中最大分钟数，10px 高，仅右端 5px 圆角；日期、条形起点和数值末尾分别共享对齐边。
- 环形图外径 120px、环宽 20px，保留原始比例绘制。正时长按降序取前五场，其余汇总「其他」；相同时长用 recording ID 稳定排序。图例整数百分比用最大余数法保证合计 100%。
- 未知和零时长保留明细与图例，不绘制扇区。未知以「时长未知」「—」和空心标记说明，灰色实心扇区只表示「其他」。无有效时长显示空环及文字说明。
- 六色使用给定 OKLCH 色板，深色 L 各提升 0.08。五个彩色色相间距至少 30°；第六色是指定的低彩度中性灰，与第一色共用 250° 并非独立彩色色相。
- 图例保留标题、时长、百分比；标题省略时可悬停查看全文、键盘聚焦展开或打开会议详情。扇区与图例双向悬停联动，键盘焦点也联动高亮。SVG 有 role、整体 title 和每个扇区的 title。
- 数字卡采用 32px/600，小时单位 14px/400、基线对齐；分析 16px/1.7、muted 色、最大 68ch。历史选中态为 accent 10% 背景的胶囊。
