## 容器与视觉清理

- 删除筛选摘要、日期帮助、总结重复元信息及其无用 CSS；清除失效的 `aria-describedby`。
- 复制和同步状态节点用于 JS 动态错误反馈，保留功能节点，空内容时不占布局；不是单纯承载说明的空壳。
