# T5：层级切换与近八周对比

当前基线的 `board.js` 已包含层级切换监听，线上返回的文件哈希与基线相同。没有证据表明当前版本缺少监听。此次明确初始化按钮与面板状态，并为脚本和样式更新资源版本号，避免客户端沿用旧缓存；旧客户端缓存是否为原故障根因未证实。点击、Enter、Space 切换只操作 `hidden` 与 `aria-pressed`，不发送网络请求。

`tag_time.weekly_allocation(store, *, weeks=8, today=None)` 按上海日期返回正序自然周。每周直接调用原 `week_allocation`，完整周截止周日，本周截止 today；保留空周，不修改原聚合结构与口径。GET 不触发模型或补判历史主标签；旧会议没有主标签时仍计入「未分类」。历史聚合失败仅显示对比区暂不可用，不影响既有数字与饼图的回退。

SVG 横向堆叠图按八周最大总分钟统一缩放，保留每周聚合顺序。同一分类在所有行共享颜色，先复用本周分类饼图已有配色，再将历史独有分类分配到剩余 `--chart-1..6`；「其他」「未分类」沿用饼图专色。原饼图生成与展示保持不变。浅色带使用分类色与 `fill-opacity=0.18`，仅连接相邻两周都存在的分类（零分钟保留退化连接），空周及缺失分类断开。连接置于矩形后方。

行内容高 18px、间距 10px，矩形高 14px、圆角 3px。外层 SVG 标签固定 12px，内层 viewBox 横向自适应；ResizeObserver 在容器宽度变化后更新横坐标，保持条高与圆角不缩小。390px 仍显示全部八周，图例换行，空周显示空条与 0.0h。无图表库或新增依赖。
