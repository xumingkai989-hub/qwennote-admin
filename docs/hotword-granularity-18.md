# 工单 18：热词粒度收敛到词本身

编辑后只处理字符 diff 的 replace/delete 原文片段；insert、纯标点、大小写或空格差异不建议。删除没有非空标准词时不会生成无法存入的空词条。首尾空白、Unicode 标点剥离，中文候选最多 12 字、纯 ASCII 最多 24 字，仍须通过录入的 20 字上限；超过候选上限先移除相同前后缀，仍超长则丢弃。最多三条，按最终候选去重。

**示例与字符 diff 的区别**：`星河直播 → 星火直播` 的字符 opcode 实际为 `河 → 火`。为保留词本体，在原始 opcode 基础上仅尝试按标点、分隔词和英文词组边界补全短词；不会固定补前后 6 字。示例 `本次会议中星河直播的转化率` 精确得到 `星河直播 → 星火直播`。这是一种保守、无联网的边界启发式，不是中文分词模型；没有可靠短边界时保留最小片段。最终用户仍可不选建议。

热词新增/更新/批量：标准词 1–20 字，拒绝 `，。！？；：、`、换行、控制字符、连续两个普通空格及 `< >`。备注保持 1000 字单行限制。别名按中英文逗号拆分，每条使用同一词语校验；非法别名逐条跳过，单条表单返回已保存和跳过原因，批量返回 `skipped_aliases`（所在 item 下标、原别名、原因）。非法标准词整次请求失败，批量不部分写入。表单错误紧邻输入框，更新失败保留草稿并展开编辑入口；不使用弹窗。

启动在原迁移事务中添加 `needs_review INTEGER NOT NULL DEFAULT 0`，扫描 term 超过 20 字或含指定句子标点的词条并置 1。仅写标记，不改 term/aliases/note、录音原文或手动正文。列表黄色提示为“这条像是整句，建议改成词语本身”，同一行提供编辑入口。用户保存有效词条时才清除标记。升级兼容旧 schema，重复启动幂等。

判断 prompt 与解析器要求 span 是原文真实出现且唯一定位的词本体，最多 12 字，不含 Unicode 标点或换行，不跨标点。非法 span 单条丢弃，同一上下文最多用强化约束重试一次（仍包含在字段总计 30 秒内）；持续非法记 `judge_failed`。其他有效 span 可以保留。原有位置绑定、历史归档、人工撤销与数据库原文保护继续生效。

验证：原 1007 项 Python 测试保留，新增 43 项（总计 1050），含无网络的假模型 transport。旧断言中“插入产生建议”“固定六字上下文”“HTML 可作为新热词”按新合同更新；旧 HTML/Markdown 词条的安全展示改用历史数据库数据构造，原有保护覆盖保留。21 项 JS 单测及原编辑/判断浏览器回归继续执行；新增词粒度浏览器测试覆盖桌面和手机短词弹层、复核提示/编辑入口、输入下错误、不弹窗、非法别名回报。截图均为合成数据，生产不会为截图创建整句热词。
